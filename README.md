# MLOps Course — Homework 1: Environment, Inference & Hardware Benchmark

Репозиторий содержит решение домашнего задания №1: развертывание воспроизводимого рабочего окружения, настройка детерминированного инференса открытой языковой модели и профилирование аппаратных ресурсов машины.

## Стек технологий
- **Python**: 3.12+
- **Пакетный менеджер**: `uv` (с фиксацией дерева зависимостей в `uv.lock`)[cite: 1]
- **Фреймворки**: PyTorch, Hugging Face Transformers, Accelerate[cite: 1]
- **Базовая модель**: `Qwen/Qwen3-0.6B` (с возможностью переключения на `HuggingFaceTB/SmolLM2-135M-Instruct`)[cite: 1]
